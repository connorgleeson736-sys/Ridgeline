# South Island overview imagery — Ridgeline 3D 0.3.0

Download all six ZIP files here. Sign in to GitHub if needed, open each ZIP's file page, then select **Download raw file** (the download arrow).

In Ridgeline 3D 0.3.0 choose **Layers → Download offline region → Import overview ZIPs**. Select all six together (long-press for multi-select), or import one part at a time. Keep the app open until **Ready for offline use · 6/6 packs**. Imports verify SHA256 and exact size, and retain completed packs after interruption.

The six files add the missing zoom 9–12 imagery to the downsampled zoom 0–8 images already in the APK. Additional payload: 364,762,502 bytes (364.8 MB). Allow about 750 MB temporarily for both ZIP downloads and imported data. You can remove the downloaded ZIPs after successful import. Use these six prepared ZIPs, rather than the original fifteen source exports.

Scope: South Island, Rakiura and nearby islands. Imagery only: download regions for offline elevation/3D terrain and profiles. File zooms can differ from camera zooms. Separate Cook-reference corrections are excluded; image pixels match the supplied original archive.

All 5,344 original overview images and every optimized range were verified against the authoritative original index. See validation.json. Data attribution: LINZ CC BY 4.0 and imagery contributors; existing Esri imagery-gap coverage. On-map attribution is retained.
