## Verification results

- Clean preview baseline: **55/55 mobile tests**.
- Reconciled source: **55/55 mobile tests**, including 0.15/0.16-specific coordinate cache, coverage reuse, invalidation, elevation-cache and profiling tests.
- New focused regression suite: **15/15 against source**, and **15/15 against final generated Capacitor files**. This checks the app-specific transformations, not just website modules.
- Affected Java components: Java 21 compilation and **9/9 JUnit tests**, including blocked-cancellation contention, shared consumers and validated stream EOF.
- Chromium browser workflow: **passed**, using software WebGL and controlled provider fixtures; 305 fixture requests, no page or console errors. This base-build run had no large overview packs, so it made zero real precomputed-pack reads.
- Real-worker browser transport, priority, cancellation and reference composition checks: **passed**. Android control messages use a mock bridge; this is not Android-device execution.
- Direct renderer, native residency, loading continuity, native tile unloading and regional routing checks: **passed** with controlled fixtures.
- Engine provenance and build fingerprint: regenerated and checked.

The earlier operation-count improvements still reproduce against the preview-generated engine: **524,288 → 1,024 ancestry checks**, and **6,144 → 521 parent probes** in their respective fixtures. These are not phone FPS percentages.

## Limits and future reference

No new APK was assembled, signed, installed or published. The full Android Gradle/lint workflow and all 85 original native tests were not rerun here; the nine tests cover the affected standalone Java components. Physical-device frame pacing, native WebView/driver behaviour and real provider loading remain unmeasured.

`AGENTS.md` now records the user's instruction: **always reference `android-preview-download` for Android preview work, and resolve the source commit linked by its latest release before changing code.**
