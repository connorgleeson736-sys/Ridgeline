# Ridgeline Android preview 0.1.0

Download the universal APK for an Android emulator, or the ARM64 APK for most Android phones. Android 8.0 or newer is required.

Open an APK file on GitHub and choose Download raw file. Install on a phone, or drag the universal APK onto a running Android Studio emulator.

These are development-signed preview builds from source commit 27384b94090dc0271be513d796d7a40c5193964a. See Ridgeline-validation.json for checks and remaining device testing. This branch contains downloadable builds; application source remains on main.
